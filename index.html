Optimización de Colocación de Cámaras de Vigilancia

Trabajo Terminal 2025-A012

Python GeoPandas Mongo DB Folium PSO Genetic Algorithm

Este proyecto de investigación y titulación, tuvo como objetivo modelar el problema de posicionar de n cámaras de vigilancia en el sistema C5 de la CDMX. Estimando las zonas de mayor riesgo y eligiendo la mejor combinación de regiones mediante algoritmos bioinspirados (PSO y genético). Mostrando en un servicio web una herramienta de apoyo para visualizar las regiones propuestas.

En colaboración con Eva Fuentes.
